# ДЗ №1 — две разработки мини-трекера

**Факультатив:** «Создание ИИ-агентов с нуля»  
**Вариант:** A (два независимых браузерных чата)  
**Модель:** GPT-6, режим «Высокий»  
**Дата выполнения:** 15–16 ноября 2026 года

## Как запустить

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте архив.
2. Откройте `tracker-v1.html` или `tracker-v2.html` двойным щелчком в Safari или другом браузере.
3. Сервер, установка библиотек, API-ключи и сборка не нужны.

## Состав

- `tracker-v1.html` — первая попытка без предварительной спецификации (сохранена как исходный результат).
- `tracker-v1-fixed.html` — исправление выявленных ошибок первой попытки.
- `tracker-v2.html` — вторая попытка после подготовки спецификации.
- `proposal.md`, `specs/tracker/spec.md`, `design.md`, `tasks.md` — документы **в формате OpenSpec**, подготовленные в веб-чате; OpenSpec CLI и валидатор не запускались.
- `prompts.txt` — четыре запроса, использованные в двух чатах разработки: генерация и исправление v1, создание спецификации и генерация v2.
- `report.md` — сравнение подходов и журнал фактических ручных проверок T1–T5.
- `screenshots/` — два снимка собственных проверок в Safari.

## Особенности и ограничения

Процент выполнения считается **по часам всех задач**, а не по числу задач. Для исходного примера: 8 ч всего, 2 ч готово, 25%; после завершения «Практики»: 6 ч из 8 и 75%.

Проверки выполнялись вручную в Safari. Поведение `localStorage` при открытии локальных файлов по `file://` зависит от браузера и ранее сохранённого состояния: повторное открытие не всегда показывает исходный пример. Для проверки стартовых данных использовалось приватное окно Safari. Автоматизированные тесты и OpenSpec CLI для варианта A не запускались.
