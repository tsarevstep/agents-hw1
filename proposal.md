
# Proposal: мини-трекер учебных задач

## Цель

Разработать автономный мини-трекер для учёта учебных задач на неделю.

Пользователь должен иметь возможность добавлять и удалять задачи, отмечать их выполнение, просматривать список активных задач и отслеживать прогресс по запланированным часам.

## Границы проекта

### Входит в объём

- Отображение списка учебных задач.
- Добавление задачи с названием и оценкой в часах.
- Удаление задачи.
- Переключение статуса выполнения (done).
- Фильтрация списка по активным задачам.
- Расчёт общего количества часов.
- Расчёт выполненных часов.
- Отображение прогресса в процентах.
- Валидация пользовательского ввода.
- Читаемый интерфейс на ширине 390 px.

### Не входит в объём

- Серверная часть и внешние API.
- Авторизация пользователей.
- Подключение CDN и внешних библиотек.
- Дополнительные функции планирования.

## Формат результата

Вариант A:
- Один файл `tracker-v2.html`.
- HTML, CSS и JavaScript внутри файла.

Вариант B:
- `index.html`
- `styles.css`
- `app.mjs`
- `domain.mjs`
- `tests/acceptance.test.mjs`

Оба варианта должны выполнять одинаковые функциональные требования.

## Необязательное улучшение

Сохранение задач в localStorage.

Если хранилище недоступно, приложение должно показывать понятное сообщение и продолжать работу с данными в памяти.

## Критерий завершения

Мини-трекер удовлетворяет всем обязательным требованиям и проходит предусмотренные сценарии приёмки WHEN/THEN.
